# Vizsgafüzet

Study site for the Hungarian cultural knowledge exam (*magyar kulturális ismereti vizsga*).
Lessons, vocabulary, past questions, practice and a mock exam in Hungarian, English and Turkish.

- Single file: `index.html` (no build step)
- Progress is saved in the visitor's browser (localStorage) only
- Hosted with GitHub Pages

Independent study aid, not connected to any authority. Past questions come from candidates' reports; check the official OIF material before the exam.
